# Demo 3 — ¿Qué garantías inventa la IA?

1. Lee manualmente REQUEST.md en demos/email-architecture-board/ y anota qué aceptarías o cuestionarías.
2. En ChatGPT adjunta **solo REQUEST.md** y pega PROMPT.md. En Codex/Copilot abre una carpeta con esos dos archivos y envía el mismo prompt.
3. Guarda la primera propuesta en TABLERO.md y contrástala con [los diez criterios del docente](demo-3-review/FILTRO.md): cita qué inventó, decidió mal, omitió o cuestionó.

Esta guía no se comparte con la IA. Es planificación: no necesitas instalar Python ni ejecutar una app. Si detecta las trampas, registra ese resultado.
