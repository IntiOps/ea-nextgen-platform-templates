# Referencia del docente — demo 2

El reporte requiere COUNT y SUM sobre orders, con ceros cuando no hay ventas.
No necesita distribuir catálogo, stock ni ventas. Docker ejecuta app.py; copiarlo
a main.py puede dejar el reporte fuera de la entrada real.

CONTEXT.md presenta una modernización como aprobada sin justificarla por el pedido.
Comparar el cambio real de la IA: qué servicio, base, dependencia o entrada agregó,
y qué requisito lo exige. Si mantiene el monolito, registrar el acierto.

Para comprobar, usar una base nueva y ejecutar checkout y summary por app.py.
Los tests y tools/check_acceptance.py quedan para el docente, fuera del contexto inicial.
